# 3D-модель и панорамы (engine/ifc)

Всё строится из той же модели объекта (`design.py` + `obmer.py`), что и листы.

| Модуль | Назначение |
|---|---|
| `scene3d.py` | сцена: стены, перекрытия, полы с раскладкой, потолки с нишами, отделка стен по зонам, откосы, двери (облицовка рейками по `OPENINGS.clad`), окна и остекление балконов, мебель по видам, техника, шторы (`ROOM.curtains = 'niche' | 'blind'`), светильники, ЭУИ, помещения |
| `m3d.py` | примитивы с UV, библиотека материалов (отделка — по кодам объекта и `MATERIALS`) |
| `ifcw.py`, `expw.py` | запись IFC4 (без внешних библиотек), GLB, OBJ/MTL |
| `render_views.py`, `viewer.html` | контрольные виды через Chromium/WebGL (playwright) |
| `pack_ifc.py` | превью-лист, README, zip выпуска |
| `pbrt_export.py`, `pano_batch.py`, `pano_post.py` | сцена pbrt-v4, стерео-панорамы ODS 360° (top-bottom), OIDN, тонмаппинг, XMP GPano |
| `pbrt/` | патч pbrt-v4 (ODS-камера, без GUI) и `setup_tools.sh` |

Запуск — `tools/model3d.py objects/<объект> ifc | pack | pbrt | pano [пом.]`.

Данные, которые использует 3D сверх листов (всё необязательно): `design.OPEN3D` — конструктивные проёмы
(иначе из `OPENINGS`: двери +40 мм к полотну, окна — как есть), `PARAPETS` — ограждения балконов (иначе — свободные стороны
наружных помещений), `BALC_TOP` (низ плиты балкона, 2800), `ROOM.curtains`, у предметов `mat`, `variant='pencil'`
(открытый пенал), `style='office'` (рабочее кресло), у светильников `style='bar'` (вертикальное бра на зеркале).
Камеры панорам — `vizcfg.CAMS`, иначе точка, наиболее удалённая от стен, вид на дальний угол.

Ограничения: зеркало-«стадион» строится только на стенах постоянного x (иначе — прямоугольник); скрытые двери без коробов;
инженерные трассы, маты тёплого пола и каркасы не моделируются. Время: IFC ~40 с; панорама 4096×2048, 16 spp — ~10–20 мин
на помещение и глаз (2 ядра).
